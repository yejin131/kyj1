#학식(백반)식단표

- 개요   
대학교 학생식당의 주간 식단(백반)을 날짜별로 자동 생성해서 보여주는 앱입니다.  
별도 서버 없이 브라우저에서 바로 실행되며, 같은 날짜는 항상 같은 메뉴가 표시됩니다.

- 주요 기능
 달력에서 날짜 선택 후 해당 날의 점심/저녁 식단 확인
 날짜 해시 기반으로 날짜마다 다른 메뉴 자동 생성
 같은 날짜는 새로고침해도 항상 동일한 메뉴 표시
 이전달/다음달 이동 가능
 오늘 날짜 파란색 숫자로 강조 표시
 선택한 날짜 파란 테두리로 표시

- 실행 방법
1. index.html 파일을 다운로드합니다.
2. 브라우저에서 파일을 열면 바로 실행됩니다.

- 수정 방법
1. index.html 을 텍스트 편집기로 엽니다.
2. 메뉴 항목 변경: 파일 상단의 MENU_POOL 배열에서 밥/국/반찬 목록을 수정합니다.
3. 저장 후 브라우저를 새로고침하면 반영됩니다.
